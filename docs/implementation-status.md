## Открытые release gates

- Независимо выполнить `Restart & Run All` всех полных ноутбуков блоков 3–4 на заявленном GPU.
- Зафиксировать SHA-256 полных внешних датасетов и manifest scene-level split.
- Создать закрытый instructor repo и перенести туда новые независимые варианты/hidden tests.
- Провести методическую экспертизу и пилот минимум на одном потоке студентов.
- После пилота заменить `v1.0.0-rc1` на `v1.0.0` и создать семестровый тег.

До закрытия этих пунктов курс честно остаётся на стадии `technical-validation`, хотя базовый CI и открытый smoke проходят.

# Компьютерное зрение CV-46

Курс учит не запускать отдельную архитектуру, а строить воспроизводимую CV-систему: от данных и baseline до анализа ошибок, системной стоимости и границ применимости.

## Начать

1. [Установите locked-окружение](setup.md).
2. Прочитайте [общую методику эксперимента](guidelines-students.md).
3. Выберите блок и работу в [репозитории курса](https://github.com/Gorod89/ITMO_study_CV_46#структура-курса).
4. Запустите `make smoke`, прежде чем переходить к полному профилю.

## Принцип курса

```text
данные → baseline → контролируемая серия → метрики и артефакты
       → анализ ошибок → ограниченный вывод → воспроизводимый release
```

## Для кого

- студентам — задания, public tests, рубрики и быстрый технический feedback;
- преподавателям — единый протокол, release gates и разделение открытого/закрытого оценивания;
- внешним авторам — проверяемые правила добавления научных материалов и данных.

Современные ротационные темы и статьи уровня CORE A/A* собраны в [ежегодном обзоре](frontier-core-a.md).

# Публичные и закрытые оценочные материалы

[← Руководство преподавателя](guidelines-teachers.md)

## Публичный репозиторий

- формулировки и прозрачные рубрики;
- тренировочные вопросы;
- public tests и малые fixtures;
- примеры формата сдачи;
- политика академической честности и апелляции.

## Закрытый преподавательский репозиторий

```text
course-instructor/
├── solutions/
├── hidden-tests/
├── secure-test-banks/
├── exam-generators/
├── grading-examples/
├── private-datasets/
└── instructor-runbooks/
```

Доступ предоставляется по принципу минимально необходимого. Изменения журналируются, а варианты ротируются между потоками. Закрытый репозиторий не подключается как публичный submodule и не упоминается токеном в конфигурации.

## Реакция на раскрытие

1. Остановить публикацию релиза.
2. Считать материал раскрытым, даже если текущий файл удалён.
3. Заменить вопросы/ключи и проверить forks, releases, Actions artifacts и историю Git.
4. Для ещё не опубликованного производного репозитория создать чистую историю без закрытого материала.
5. Зафиксировать инцидент и обновить процедуру review.

Автоматический детектор сходства не выносит решение о нарушении. Он инициирует индивидуальную защиту, проверку истории Git и возможность студента объяснить происхождение работы и изменить выбранный фрагмент.

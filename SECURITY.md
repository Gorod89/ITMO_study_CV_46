# Безопасность

Для уязвимостей кода используйте приватное сообщение владельцу репозитория или GitHub Private Vulnerability Reporting, если оно включено. Не публикуйте exploit, токен, персональные данные или закрытый оценочный материал в issue.

Особенно чувствительны:

- ключи и hidden tests;
- изображения лиц, номера, бейджи и метаданные CCTV;
- токены сервисов и URL закрытых данных;
- небезопасная десериализация весов/артефактов;
- зависимости и model checkpoints из непроверенных источников.

В отчёте укажите затронутую версию, минимальное воспроизведение и возможный ущерб. Поддерживаемой считается последняя стабильная версия; кандидат релиза поддерживается только для проверки исправления.

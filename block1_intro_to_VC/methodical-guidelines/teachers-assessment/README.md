# Методические указания преподавателям по оцениванию. Блок 1

[← Блок 1](../README.md) · [Единая модель оценивания](../../../docs/guidelines-teachers.md) · [Описания КИМ](../students/README.md)

Все работы блока оцениваются по [единой 10-балльной рубрике](../../../docs/guidelines-teachers.md#1-модель-оценивания) (К1 реализация 0–3, К2 эксперимент 0–3, К3 анализ 0–2, К4 оформление и защита 0–2). Ниже — проверяемые элементы каждого КИМ, конкретизирующие критерий К1, и типичные ошибки, снижающие баллы.

## Привязка КИМ к индикаторам

| КИМ | Индикатор (уровень) | Что подтверждает |
|---|---|---|
| ДЗ1 | DL-3.2 (Б) | представление изображений, фильтрация (включая частотную), морфология |
| ДЗ2 | DL-3.2 (С) | проективные преобразования, RANSAC |
| ДЗ3 | DL-3.2 (С) | преобразование Хафа, контурный анализ |
| ЛР1 | BD-1.3 (Б→С), DL-3.2 (Б), DL-3.3 (Б) | постановка задач CV, метрики, очистка зашумлённых изображений, применение готовых CNN |
| ЛР2 | DL-3.2 (Б→С) | комбинация методов блока в прикладном конвейере |

## Проверяемые элементы (К1) по работам

**ДЗ1:** не менее 3 фильтров и 2 типов шума; PSNR/SSIM посчитаны корректно (по эталону, а не по зашумлённому изображению); бинаризация Оцу и адаптивная сравнены на неравномерно освещённом изображении; морфологические операции применены осмысленно (открытие против «соли», закрытие против «перца»).

**ДЗ2:** матрицы преобразований выписаны и применены явно (не только вызовы высокоуровневых функций); гомография по 4 точкам корректна; сравнение МНК и RANSAC проведено при контролируемой доле выбросов (серия, а не один запуск).

**ДЗ3:** исследована чувствительность Кэнни к порогам; характеристики контуров посчитаны; Хаф находит примитивы при наличии помех; показана зависимость результата от разрешения аккумулятора.

**ЛР1:** метрики соответствуют задачам (не accuracy для детекции); классический и нейросетевой подходы сравнены на одном и том же разбиении; влияние предобработки показано количественно.

**ЛР2:** конвейер прогнан на ≥10 разнородных снимках; есть метрика качества выравнивания; разобраны случаи отказа (блики, обрезанные углы, фон, близкий по яркости к документу).

## Типичные ошибки

- метрики качества фильтрации считаются относительно зашумлённого изображения, а не эталона;
- RANSAC «сравнивается» с МНК на данных без выбросов (разницы нет — вывод неверен);
- пороги Кэнни и параметры Хафа подобраны под один кадр и выдаются за универсальные;
- в ЛР1 классический и нейросетевой методы оцениваются на разных подмножествах;
- в ЛР2 демонстрируются только удачные кадры, отказные случаи скрыты.

## Вопросы для защиты (примеры)

1. Почему для этого типа шума вы выбрали именно этот фильтр? Что покажет частотная область?
2. Покажите в коде, где оценивается гомография. Что произойдёт при трёх парах точек?
3. Как изменится аккумулятор Хафа при увеличении шага по углу?
4. Почему в ЛР2 конвейер отказал на этом кадре и как бы вы это исправили?

## Как использовать ресурсы блока при разработке и проведении КИМ

- **Датасеты** ([resources/datasets](../../resources/datasets/README.md)). Для ДЗ1–ДЗ3 достаточно небольших наборов свободных изображений (включая тестовые изображения scikit-image); для ЛР2 нужны фотографии документов под углом — рекомендуемые открытые наборы указаны в карточках. Поощряйте съёмку собственных кадров: это исключает копирование решений и даёт разнородные отказные случаи.
- **Учебники** ([resources/textbooks](../../resources/textbooks/README.md)). Гонсалес и Вудс — базовый справочник по фильтрации и морфологии (ДЗ1, ДЗ3); Szeliski — по преобразованиям и оценке гомографии (ДЗ2, ЛР2).
- **Библиотеки** ([resources/software/python-libs](../../resources/software/python-libs/README.md)). Работы блока рассчитаны на OpenCV + NumPy + scikit-image; фиксируйте мажорные версии в задании — сигнатуры функций OpenCV между версиями меняются.
- **Статьи** ([resources/papers](../../resources/papers/README.md)) — первоисточники методов (Кэнни, Оцу, RANSAC, Хаф) для докладов сильных студентов и дополнительных вопросов на защите.

## Вариативность

Индивидуальные варианты формируются выбором: набора изображений, типа шума и его интенсивности (ДЗ1), доли выбросов в соответствиях (ДЗ2), типа примитивов (ДЗ3), типа документа (ЛР2). Рубрики при этом не меняются.

## Тиражирование

При переносе блока на другую предметную область достаточно заменить материал изображений (например, медицинские снимки, аэрофото, кадры производственной камеры) — задания и критерии от домена не зависят.

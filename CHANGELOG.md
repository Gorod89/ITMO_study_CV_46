# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют Semantic Versioning.

## [Unreleased]

### Добавлено

- CPU smoke-профиль и автоматическая проверка структуры репозитория и ноутбуков.
- Воспроизводимое Python-окружение, единые команды `make setup`, `make test`, `make smoke`, `make docs`.
- Руководства по установке, воспроизводимости, данным, выпуску и безопасному оцениванию.
- Научный обзор публикаций CORE A/A* с планом учебной интеграции.
- Карточки данных, реестр датасетов и политика лицензий.

### Изменено

- Блок 3 приведён к единой прогрессии scaffolding; ResNet и YOLO переработаны.
- Статусы материалов теперь отражают фактическую техническую валидацию.
- Политика академической честности учитывает индивидуальную проверку и право объяснения.

### Безопасность

- Ключи к банкам вопросов удалены из публичных материалов.
- Зафиксировано разделение public tests и закрытых решений/hidden tests.

## [1.0.0-rc1] — 2026-07-29

- Первый кандидат стабильного русскоязычного релиза курса.

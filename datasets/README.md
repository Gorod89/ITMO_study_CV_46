# Данные курса

[← К описанию курса](../README.md)

`registry.yml` — машиночитаемая точка входа. Карточки в `cards/` описывают происхождение, лицензию, разбиение, PII, смещения и ограничения конкретного набора.

## Правила

1. Датасет без точной версии и проверяемого источника не используется в обязательной работе.
2. Загруженный архив проверяется по SHA-256 до распаковки.
3. Split хранится manifest-файлом или однозначно генерируется версионируемым алгоритмом с seed.
4. Кадры одной сцены, пациента, объекта или видеопоследовательности не разделяются между train и test.
5. Лица, номера, бейджи и иные идентификаторы рассматриваются как возможные персональные данные.
6. Лицензии изображений, аннотаций, кода загрузчика и весов модели проверяются раздельно.
7. Запись без checksum получает статус `candidate` и не может войти в стабильный полный профиль.

## Локальное размещение

Большие данные хранятся в `data/`, исключённом из Git. В репозитории допустимы только малые fixtures с явным происхождением и лицензией. Никогда не коммитьте скачанный датасет только потому, что он доступен без авторизации.

## Добавление

Создайте карточку из [шаблона](cards/TEMPLATE.md), добавьте запись в `registry.yml`, зафиксируйте manifest split и public fixture. Pull request должен показывать успешный smoke без доступа к полному набору.

# Методические указания преподавателям по оцениванию. Блок 2

[← Блок 2](../README.md) · [Единая модель оценивания](../../../docs/guidelines-teachers.md) · [Описания КИМ](../students/README.md)

Все работы блока оцениваются по [единой 10-балльной рубрике](../../../docs/guidelines-teachers.md#1-модель-оценивания) (К1 реализация 0–3, К2 эксперимент 0–3, К3 анализ 0–2, К4 оформление и защита 0–2). Ниже — проверяемые элементы каждого КИМ и типичные ошибки.

## Привязка КИМ к индикаторам

| КИМ | Индикатор (уровень) | Что подтверждает |
|---|---|---|
| ДЗ4 | DL-3.2 (Б→С) | детекторы характеристических точек, дескрипторы, фильтрация соответствий |
| ДЗ5 | DL-3.2 (С) | классические алгоритмы сегментации, включая графовые и mean shift |
| ДЗ6 | DL-3.1 (С) | извлечение кадров, модели фона, выделение объекта внимания |
| ЛР3 | DL-3.1, DL-3.2 (С) | комбинирование детекции и сопровождения в трекинге |
| ЛР4 | DL-3.4 (С) | эпиполярная геометрия, стереозрение, элементы фотограмметрии |

## Проверяемые элементы (К1) по работам

**ДЗ4:** повторяемость измерена на контролируемых искажениях (а не «на глаз»); соответствия отфильтрованы минимум двумя способами; показан пример отказа template matching (масштаб/поворот).

**ДЗ5:** ≥3 метода из разных семейств (пороговое/региональное, кластеризационное, графовое); IoU/Dice посчитаны по эталонной разметке; сравнение по качеству и времени на одних и тех же изображениях.

**ДЗ6:** модель фона сравнена минимум с разностным методом; маски очищены морфологией; полнота/точность посчитаны на размеченном фрагменте, а не описаны словесно.

**ЛР3:** есть инициализация, обработка потери и повторный захват; сравнение ≥2 стратегий на одном видео с ground truth; IoU по кадрам и доля потерь посчитаны.

**ЛР4:** калибровка выполнена, ошибка репроекции указана; карта диспаратности построена и параметры исследованы серией; глубина проверена на объекте с известными размерами.

## Типичные ошибки

- повторяемость детекторов оценивается на разных сценах — сравнение несопоставимо;
- ratio test применяется с порогом «по умолчанию» без исследования влияния;
- сегментация оценивается только визуально, без IoU по эталону;
- в ДЗ6/ЛР3 параметры подобраны по тому же фрагменту, на котором посчитаны метрики;
- в ЛР4 не указана ошибка репроекции калибровки, глубина не проверена по известному размеру;
- сравнение времён работы при разных разрешениях входа.

## Вопросы для защиты (примеры)

1. Покажите кадр, где ваш трекер теряет объект. Почему это происходит и как реализован повторный захват?
2. Почему при увеличении порога ratio test растёт число соответствий и что происходит с их качеством?
3. Как изменится карта диспаратности при уменьшении блока сопоставления?
4. Что даст переразметка эталона другим человеком для ваших метрик сегментации?

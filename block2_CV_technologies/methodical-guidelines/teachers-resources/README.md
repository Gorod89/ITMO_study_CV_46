## Как использовать ресурсы блока при разработке и проведении КИМ

- **Датасеты** ([resources/datasets](../../resources/datasets/README.md)). Для ДЗ4 — эталонные последовательности с известными гомографиями (Oxford Affine/graffiti); для ДЗ5 — наборы с эталонной сегментацией (BSDS500); для ДЗ6/ЛР3 — видео с разметкой треков (MOT17) либо собственная съёмка со статичной камеры; для ЛР4 — стереопары Middlebury и собственная калибровочная съёмка.
- **Учебники** ([resources/textbooks](../../resources/textbooks/README.md)). Szeliski — сопоставление признаков и трекинг; Hartley & Zisserman — эпиполярная геометрия для ЛР4 (материал избыточен для С-уровня — рекомендуйте главы, а не книгу целиком).
- **Библиотеки** ([resources/software/python-libs](../../resources/software/python-libs/README.md)). SIFT доступен в основном пакете opencv-python начиная с 4.4; для некоторых трекеров (CSRT/KCF) требуется opencv-contrib-python — укажите это в задании явно.
- **Статьи** ([resources/papers](../../resources/papers/README.md)) — первоисточники (Lowe, Harris, Lucas–Kanade, mean shift) для докладов и углублённых вопросов.

## Вариативность

Индивидуальные варианты: сцена и тип искажений (ДЗ4), семейства методов сегментации (ДЗ5), видеоролик и целевой объект (ДЗ6, ЛР3), объект реконструкции (ЛР4). Собственная съёмка студента предпочтительна: она делает работы несравнимыми между собой и даёт честные отказные случаи.

## Тиражирование

Блок переносится на другие домены заменой видеоматериала (транспорт, производственная линия, спортивная аналитика); стереочасть ЛР4 требует лишь доступной пары камер или смартфона с двумя ракурсами.

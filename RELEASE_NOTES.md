# Примечания к выпуску v1.0.0-rc1

**Дата:** 29 июля 2026 года  
**Назначение:** техническая апробация перед стабильным релизом  
**Семестровый снимок:** кандидат `2026-fall`

Релиз превращает набор материалов ветки разработки в воспроизводимый открытый учебный продукт. Содержание курса сохранено, но добавлены единая точка входа, фиксированное окружение, автоматические проверки, CPU smoke-режим, явные стадии готовности и правила сопровождения.

## Что проверить перед v1.0.0

- [ ] CI проходит из чистого клона на Python 3.11 и 3.12.
- [ ] Все ноутбуки проходят структурную проверку; обязательные smoke-ноутбуки выполняются без сети.
- [ ] Для каждого внешнего датасета зафиксированы версия, источник, лицензия, split и checksum.
- [ ] Блоки 3–4 прошли независимый `Restart & Run All` в полном профиле.
- [ ] Закрытые ключи и решения отсутствуют во всей публикуемой истории.
- [ ] Не менее одной студенческой группы прошло пилот, замечания отражены в changelog.

## Совместимость

- Python 3.11–3.12.
- Smoke-профиль рассчитан на CPU и 8 ГБ RAM.
- Полные задания глубокого обучения могут требовать GPU 6–8 ГБ или предоставленного вузом окружения.

Известные ограничения перечислены рядом с заданиями и в [обзоре frontier-модулей](docs/frontier-core-a.md).

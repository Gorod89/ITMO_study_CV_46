## Как использовать ресурсы блока при разработке и проведении КИМ

- **Датасеты** ([resources/datasets](../../resources/datasets/README.md)). ЛР1–ЛР2 используют CIFAR-10 (загружается автоматически через torchvision); ЛР3–ЛР4 — изображения с разметкой в COCO/VOC-формате; ЛР5 — индивидуальный датасет студента (рекомендуемый источник — Roboflow Universe, там же конвертация в формат YOLO). Требуйте указания лицензии выбранного датасета в отчёте.
- **Учебники** ([resources/textbooks](../../resources/textbooks/README.md)). Гудфеллоу и др. — теоретическая база; d2l.ai и материалы CS231n — практические разборы архитектур, удобны как материал для самостоятельной подготовки к защите.
- **Библиотеки** ([resources/software/python-libs](../../resources/software/python-libs/README.md)). Базовый стек: PyTorch + torchvision; для ЛР5 — ultralytics; для метрик детекции — pycocotools/torchmetrics. Зафиксируйте версии в начале семестра: API ultralytics меняется часто.
- **Статьи** ([resources/papers](../../resources/papers/README.md)) — оригинальные работы (ResNet, ResNeXt, Faster/Mask R-CNN, YOLO): используйте как основу докладов и П-уровневых вопросов.

## Вычислительные ресурсы

Все ЛР рассчитаны на один бесплатный GPU (Colab/Kaggle): в ЛР2 и ЛР5 обучение укладывается в десятки минут на сокращённых наборах. Для потока без GPU предусмотрите уменьшение разрешения/эпох — рубрики этого не касаются, т.к. оценивают методику, а не абсолютные метрики.

## Вариативность

Индивидуализация: подмножество классов CIFAR-10 (ЛР1–ЛР2), набор изображений для анализа ошибок (ЛР3–ЛР4), собственный датасет и гипотеза (ЛР5). ЛР5 по построению уникальна у каждого студента — это основной антиплагиатный механизм блока.

## Тиражирование

Блок легко привязывается к предметной области вуза заменой датасета ЛР5 (сельхоз-культуры, дефекты производства, медицинские снимки) без изменения ноутбуков ЛР1–ЛР4.
